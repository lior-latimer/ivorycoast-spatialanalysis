This project is a spatial analysis using DHS survey data in Côte d’Ivoire between September and December 2021. 

Section 1: Exploratory spatial analysis of open defecation for households in Côte d’Ivoire

Section 2: Descriptive spatial analysis of malaria infections in young children in Côte d’Ivoire

Relevant topics: Choropleth maps, spatial autocorrelation, Moran's I, empirical semivariogram fitting, high-risk area identification

Completed as part of the Spatial Epidemiology, LSHTM
